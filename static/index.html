Problem Statement

In modern automated industrial environments, unexpected machine breakdowns lead to catastrophic downtime, secondary equipment damage, and immense revenue losses. However, machine failures are statistically rare events, creating extreme class imbalance.

Predictive maintenance leverages continuous sensor streams to forecast anomalies and imminent component breakdown before critical threshold collapse occurs, allowing operations teams to transition from reactive panic to strategic condition-based servicing.

Project Objectives

This AIDL course project rigorously investigates AI-driven binary failure prediction on the UCI AI4I 2020 benchmark:

  • Formulate domain-specific physical features (temperature differential, power consumption, cumulative tool strain).
  • Train and evaluate three distinct algorithmic paradigms: Logistic Regression, Random Forest, and a Deep Neural Network (DNN).
  • Address extreme class imbalance (~3.39% failures) through class-weighted loss and optimal decision threshold calibration.
  • Benchmark metrics using precision-recall dynamics rather than misleading raw accuracy.

Engineered Domain Features

Standard raw sensors alone cannot fully capture thermodynamic and mechanical stress degradation. The following physics-guided features were engineered:

  • Temperature Difference ($\Delta T$): Temp_diff = Process_temperature - Air_temperature
    Quantifies convective thermal dissipation efficiency in Kelvin. Heat Dissipation Failures (HDF) occur when thermal buildup cannot be expelled.
  • Rotational Mechanical Power ($P$): Power = Torque * Rotational_speed * (2 * π / 60)
    Mechanical power consumed in Watts. Power Failures (PWF) trigger when power output falls outside safe operational envelopes.
  • Cumulative Tool Strain ($S$): Strain = Tool_wear * Torque
    Mechanical stress accumulation product (min · Nm). Overstrain Failures (OSF) occur when worn tools undergo peak torque loads.

Study Limitations
  • Synthetic Benchmark Dataset: The AI4I 2020 dataset is explicitly a synthetic benchmark generated via physical simulation models. It cannot capture unexpected factory environments, sensor drift, or novel failure modes not programmed into the simulator.
  • Single Train/Validation/Test Split: Experiments were executed on a fixed 70/15/15 stratified partition rather than repeated $k$-fold cross-validation, leaving potential partition variance unmeasured.
  • Small Test Failure Sample Size: With only ... failures in the test set, statistical confidence intervals for precision and recall are wide.
  • Constrained Hyperparameter Search: Exploration was conducted with manual grid exploration rather than exhaustive Bayesian or evolutionary hyperparameter sweeps.
  • No Real Plant Validation: Models were not validated against live physical telemetry collected from production CNC machines or mills under actual manufacturing loads.
Future Scope & Industrial Roadmap
  • Time-Series Sequence Modeling: Transition from static point-in-time snapshot features to sequential sensor telemetry using LSTM, GRU, or Temporal Convolutional Networks (TCN) to forecast Remaining Useful Life (RUL).
  • Unsupervised Anomaly Detection: Implement Deep Autoencoders or Variational Autoencoders (VAEs) to identify zero-day failure anomalies that lack labeled training examples.
